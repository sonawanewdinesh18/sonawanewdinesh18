## 🛡️ DeepVision

### Hybrid Deepfake Detection Framework & Full-Stack AI Platform

DeepVision is an AI-powered system for detecting manipulated **images and videos** using a hybrid deep learning architecture.

### 🧠 AI Architecture

```text
                  Input Image / Video
                          │
                          ▼
                    Preprocessing
                          │
                 ┌────────┴────────┐
                 │                 │
                 ▼                 ▼
          EfficientNet-B0       ViT-B/16
                 │                 │
                 │                 │
          Local Features      Global Features
                 │                 │
                 └────────┬────────┘
                          ▼
                    Feature Fusion
                          │
                          ▼
                    Classification
                          │
                 ┌────────┴────────┐
                 ▼                 ▼
                Real          Manipulated
```

### 🔧 Technology Stack

`Python` · `PyTorch` · `EfficientNet-B0` · `ViT-B/16` · `FastAPI` · `React` · `PostgreSQL` · `Supabase` · `Docker`

### 📊 Model & Research Results

| Metric           |                         Result |
| ---------------- | -----------------------------: |
| Training Dataset |         120,000 labeled images |
| Datasets         |         FaceForensics++ + DFDC |
| Architecture     |     EfficientNet-B0 + ViT-B/16 |
| Accuracy         |                        **98%** |
| ROC-AUC          |                     **0.9973** |
| Task             | Binary Deepfake Classification |

### 💻 Engineering Work

* Developed a hybrid **CNN + Vision Transformer** model
* Combined local texture features with global spatial features
* Created image and video detection workflows
* Implemented video frame extraction and analysis
* Built model inference APIs using FastAPI
* Developed the frontend using React
* Integrated Supabase/PostgreSQL
* Implemented authentication and protected routes
* Added prediction history and feedback workflows
* Designed admin functionality
* Worked with model validation and evaluation metrics
* Created UML and software architecture documentation
* Worked on frontend, backend, AI-model, and deployment integration
